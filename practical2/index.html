Practical 2: Pushing and Cloning a Repository

Aim

To push commits to a remote repository and clone it.

Task 1: Create Remote Repository

Create a bare repository and connect it as origin.

git init --bare ../html-remote
git remote add origin ../html-remote
git remote -v

Task 2: Push Commits

Push the commits to the remote repository.

git push origin main

Task 3: Clone Repository

Create a copy of the remote repository.

git clone html-remote html-copy
cd html-copy
git log --oneline

Result

Successfully pushed and cloned the Git repository.
